## Announcement Text for HackerNews

```
Show HN: ReverseEngineerEverything – Security analysis in 30 seconds

Hi HN, I built ReverseEngineerEverything (REE) to solve a real problem 
I faced: reverse engineering apps takes forever and requires expensive 
tools like Ghidra or IDA.

What REE does:
• Analyzes Android APKs for security vulnerabilities in seconds
• Works out-of-the-box (just `npm install -g ree && ree analyze app.apk`)
• AI-powered explanations (integrates with Claude for vulnerability insights)
• Extensible framework (add support for new formats in 50 lines of code)

Why REE is different from REA (the existing tool):
• 30-second setup vs 2+ hours with REA
• No Ghidra/IDA required
• Built-in AI integration
• Community-driven (easy to add new analyzers)

Current MVP detects:
✅ Dangerous permissions
✅ Exported components without protection
✅ Debuggable builds
✅ Hardcoded secrets/API keys
✅ WebView vulnerabilities

Perfect for security researchers, bug bounty hunters, and mobile developers.

MIT licensed, open-source, and we'd love contributions.

GitHub: https://github.com/Ankitajainkuniya/ReverseEngineerEverything
```
