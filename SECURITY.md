# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in ReverseEngineerEverything, please email **security@reverseengineereverything.dev** with:

1. Description of the vulnerability
2. Steps to reproduce
3. Potential impact
4. Suggested fix (if any)

**Do not** open a public issue for security vulnerabilities. We take all security reports seriously and will work with you to resolve them quickly.

## Security Considerations

When using REE:

- **Analyze untrusted APKs in isolation** - Do not analyze unknown applications on systems with sensitive data
- **Keep dependencies updated** - Run `npm update` regularly
- **Report security issues responsibly** - Use the process above
- **Understand limitations** - REE is a static analysis tool and cannot detect all vulnerabilities

## Supported Versions

| Version | Supported |
|---------|-----------|
| 1.0.x   | ✅ Yes    |
| < 1.0   | ❌ No     |

We recommend always using the latest version.
